# Changelog

All notable changes to the **BNS VSCode Theme** extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-01

### Added
- Initial release of BNS VSCode Theme.
- **BNS Dark** — rich dark theme with vivid, accessible colors (Catppuccin Mocha-inspired palette).
- **BNS Light** — clean light theme with clear, readable colors (Catppuccin Latte-inspired palette).
- Full semantic highlighting support (`semanticHighlighting: true`).
- Comprehensive workbench colors: editor, sidebar, activity bar, status bar, tabs, terminal, and more.
- TextMate token colors covering JavaScript/TypeScript, Python, Rust, Go, HTML, CSS/SCSS, JSON, Markdown, Shell.
- Semantic token colors for context-aware highlighting of classes, interfaces, enums, functions, decorators, and regex.
- Carefully tuned 16-color ANSI terminal palette for both variants.
